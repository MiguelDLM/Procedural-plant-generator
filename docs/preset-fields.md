# Preset field reference

Generated by `python -m core.presets docs` from the code; do not edit by hand.

Units: suffix `_m` metres, `_cm` centimetres, `_mm` millimetres, `_deg` degrees. Colours are sRGB triplets in 0..1. Ranges are the limits enforced on import (values outside are clamped).
